🇫🇷 À propos de ce dashboard

Dashboard de surveillance sismique mondiale en temps réel utilisant les données ouvertes du United States Geological Survey (USGS).

🔗 Source des données

USGS Earthquake Hazards Program — API GeoJSON publique, mise à jour en continu toutes les minutes.
earthquake.usgs.gov/earthquakes/feed/v1.0/

⌨️ Raccourcis clavier

  • / — Focus recherche
  • R — Rafraîchir les données
  • T — Basculer thème clair/sombre
  • 1–6 — Naviguer entre les onglets
  • Échap — Fermer la modale ouverte
  • F — Ajouter/retirer un favori (modale ouverte)

⚙️ Technologies

HTML5 · CSS3 (variables, grid, animations) · JavaScript ES2022 · Leaflet.js · Leaflet.markercluster · Leaflet.heat · Chart.js · API USGS GeoJSON

🧮 Formules utilisées

  • Énergie libérée : log₁₀(E) = 1.5·M + 4.8 (joules)
  • Classification profondeur : superficiel < 70 km, intermédiaire 70–300 km, profond > 300 km

⚠️ Avertissement

Ce dashboard est un outil pédagogique non officiel. En situation d'urgence, consultez les autorités sismologiques officielles (USGS, EMSC, CSEM).
